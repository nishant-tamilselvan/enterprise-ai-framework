# Enterprise AI Framework v0.1.0

**Release date:** 2026-07-26  
**Status:** Draft foundation  
**License:** CC BY 4.0

## Summary

The inaugural release establishes the repository, publication system, governance model, and initial Enterprise Context Architecture (ECA).

## Highlights

- Enterprise Context Architecture (ECA) with seven context domains centered on Requirements Management
- Initial enterprise capability and governance operating models
- Zero-trust AI, data protection, and threat-model guidance
- Starter mappings for NIST AI RMF, ISO/IEC 42001, the EU AI Act, and FedRAMP
- Public-sector RAG and regulated-enterprise blueprint outlines
- Automated documentation publishing and quality checks

## Compatibility and migration

This is a pre-1.0 draft. Content and structure may change incompatibly as public review develops.

## Known limitations

Mappings are high-level and non-certifying. Later releases will add conformance profiles, detailed control catalogs, quantitative evaluation thresholds, and complete implementation patterns.
