# Domain blueprints

Blueprints apply the core framework to recurring use cases. They are logical reference architectures. Implementation teams must tailor them to mission, law, risk, data, environment, and organizational capability.

## Available blueprints

- [Public-sector retrieval-augmented generation](public-sector-rag-blueprint.md)
- [Regulated-enterprise AI service](regulated-enterprise-blueprint.md)

## Blueprint anatomy

Each blueprint should define purpose and exclusions, actors and affected parties, context boundary, logical components, trust boundaries, data flows, risks, controls, human oversight, evaluation, operations, evidence, implementation options, and known limitations.
